## 2. ทิศและภูเขา 24

- ภูเขาที่ `m` (0 = 壬 … 23 = 亥) เริ่มที่ `337.5 + 15·m` องศา กว้าง 15° ✅ (`Get24PosAng`, `SetAAng`)
- ภูเขา 3 ลูกต่อวัง: ตำแหน่ง 0 = 地元, 1 = 天元, 2 = 人元 · วัง = `floor(m/3)` เรียง N NE E SE S SW W NW ✅
- วงกัว 64: ช่องละ `360/64 = 5.625°` (`CalDirMeta`) ✅
- **APK รับค่า "ทิศหลังบ้าน (นั่ง)"** เป็นหลัก ส่วนแอปเรารับ "ทิศหน้าบ้าน (หัน)" แล้วบวก 180° เอง ✅
- ซีกโลกใต้: APK กลับลำดับนักษัตร `index = (18 − i) % 12` ❓ (แอปเรายังไม่รองรับ)
- APK ให้เลือก "ทิศเดิม / ทิศปรับ" (`AngMode`) คือก่อน/หลังแก้มุมเบี่ยงแม่เหล็ก ✅

## 3. ดาวเหิน 玄空飛星

### 3.1 ยุค (運)
- ยุคละ 20 ปี เริ่มนับปี 1864 = ยุค 1: `period = ((year − 1864) div 20) mod 9 + 1` ✅
- APK เปลี่ยนยุคที่ **立春** ไม่ใช่ 1 ม.ค. (ปีแรกของยุค ถ้าเป็นเดือน ม.ค. หรือก่อน ~4 ก.พ. ยังนับเป็นยุคเก่า) ✅ — แอปเรารับแค่ "ปีที่สร้าง" จึงยังไม่ได้แยกช่วงนี้
- ยุค 5 ในตาราง APK โหมดละเอียด แบ่งเป็น "5 ช่วงแรกใช้ผังยุค 4 / ช่วงหลังใช้ยุค 6" (`StarAge5`) ✅

### 3.2 ตาราง `StarTab[ยุค 9][ภูเขา 24][3 คอลัมน์]` ✅
- ค่า = ดาวกลางผัง มีเครื่องหมาย: บวก = เดินหน้า, ลบ = ถอยหลัง
- ดาวภูเขา = `StarTab[P][ภูเขานั่ง][c]` · ดาวน้ำ = `StarTab[P][ภูเขานั่ง+12][c]`
- **คอลัมน์ 1 = ผังมาตรฐาน (下卦)** — `js/fs-core.js` (`houseChart`) ให้ผลตรงคอลัมน์นี้ครบ **216/216**
- คอลัมน์ 0 และ 2 = ค่าสำหรับช่วงริมภูเขา (兼) ซ้าย/ขวา ต่างจากคอลัมน์ 1 ใน 176 และ 184 ผัง ❓ น่าจะเป็นผังทดแทน (替卦)
- ตาราง `StarOP[ภูเขา/น้ำ][ยุค][ภูเขา 24]` = ผังทดแทนอีกชุด ใช้ในโหมดคำนวณ 2–3 ❓
- โหมดคำนวณ (`CalType`, ค่าเริ่ม = 1):
  - 1 = ใช้คอลัมน์ 1 ทั้งภูเขา (มาตรฐาน) — **แอปเราทำแบบนี้**
  - 0 = แบ่งภูเขาเป็น 3 ช่วง ช่วงกลางกว้าง ±d รอบกึ่งกลางภูเขา โดย `d` = 5° / 3.5° / 2° ขึ้นกับคุณภาพผัง (ผลของ `ChkCond`) นอกช่วงกลางใช้คอลัมน์ 0/2 ❓
  - 2, 3 = ใช้ `StarOP` ในช่วงริม ❓
- ยังไม่ได้ทำในแอป: ผังทดแทน (ดู §9)

### 3.3 สูตรบินดาว (ใช้ใน `fs-core.js`) ✅
- เส้นทางลั่วซู: กลาง → NW → W → NE → S → N → SW → E → SE
- ดาวภูเขา/น้ำ: เอาเลขดาวยุคในวังนั่ง/วังหัน ไปไว้กลาง บินตามขั้วหยินหยางของภูเขาตำแหน่งเดียวกันในวังบ้านเกิดของเลขนั้น
- ดาว 5 ยืมขั้วของเลขยุค
- ผังรวม: 旺山旺向, 上山下水, 雙星到向, 雙星到坐 📘

### 3.4 ดาวจร ✅ (`CalDateStar`, `CalSanSha`)
- **ดาวปี** = `(2000 − ปี) mod 9` (ปรับให้อยู่ 1–9) แล้วเปลี่ยนที่จุดเปลี่ยนปี (§4) เช่น 2026 = 1
- **ดาวเดือน**: ตามกลุ่มนักษัตรปี 3 กลุ่ม × เดือน 12 นักษัตร
  - ปี 子午卯酉: เดือน 寅 เริ่ม 8 · ปี 辰戌丑未: เริ่ม 5 · ปี 寅申巳亥: เริ่ม 2 แล้วลดทีละ 1 ต่อเดือน
- **ดาววัน**: ช่วง 冬至 → 夏至 นับเดินหน้าวันละ 1, ช่วง 夏至 → 冬至 นับถอยหลัง; เลขเริ่มคำนวณจากก้านกิ่งวันของวันสารท (ไม่ได้รีเซ็ตที่วัน 甲子 แบบบางตำรา) ❓
- **ดาวยาม**: จากกิ่งวัน + กลุ่มกิ่งปี และกลับทิศในครึ่งปีหยิน
- ดาวในวังใด = ดาวกลาง + ค่าชดเชยของวัง `N+5, NE+3, E+7, SE+8, S+4, SW+6, W+2, NW+1` (ปรับ 1–9) ✅
- ทิศของดาว 5 ในแต่ละชั้นเวลา = ทิศต้องระวัง (ปี/เดือน/วัน/ยาม)

## 4. ปฏิทิน สารท และเวลา

### 4.1 เวลาเปลี่ยนสารท ✅
- สารทละ 15° ของลองจิจูดดวงอาทิตย์ · `AstroSart(…, ชนิด, ปี, เดือน)`:
  มุมเป้าหมาย = `(เดือน − 1)·30 + ชนิด·15 + 285` โดยชนิด 0 = 節 (เริ่มเดือน), 1 = 中氣 (กลางเดือน)
- ปี 1601–2200 ใช้ตารางเวลาสำเร็จรูป (เวลาจีน UTC+8) แล้วเลื่อนเป็นเขตเวลาท้องถิ่น + DST; นอกช่วงคำนวณด้วยสูตรวงโคจร (อ้างอิง Peter Duffett‑Smith)
- แอปเรา: ใช้ Lunar.js (ซึ่งถือเวลาเป็น UTC+8) จึงต้องแปลงเวลาไทยเป็นเวลาจีนก่อนหาเสาปี/เดือน (`getExactPillars` ใน `calc.js`)

### 4.2 จุดเปลี่ยนปี (`YearChangeType`) ✅
| ค่า | เปลี่ยนปีที่ | หมายเหตุ |
|---|---|---|
| 0 | 立春 ~4 ก.พ. | มาตรฐาน (แอปเราใช้แบบนี้) |
| 1 | 冬至 ~22 ธ.ค. | ระบบ อ.มาศ (ซีกโลกเหนือ) |
| 2 | 夏至 ~21 มิ.ย. | ใช้กับซีกโลกใต้ |

### 4.3 จุดเปลี่ยนเดือน (`MonthChangeType`) ✅
| ค่า | ชื่อในแอป | ความหมาย |
|---|---|---|
| 0 | มาตรฐาน | เดือนเริ่มที่ 節, ยามเริ่มชั่วโมงคี่ (23:00, 01:00 …) |
| 1 | ระบบ อ.มาศ | เดือนเริ่มที่ **中氣**, ยามเริ่มชั่วโมงคู่ (00:00, 02:00 …) ตามเวลาสุริยะจริง, บังคับเปลี่ยนปีที่ 冬至, และ **เลื่อนทิศนักษัตร/ทิศอสูร 15°** (`AdjDeltaAng = 15° × ชนิด`, กลับเครื่องหมายในซีกโลกใต้) |
| 2 | ฤกษ์ 2 ระบบ | แสดงทั้งสองแบบ |
- ระบบ อ.มาศ เปิดได้เฉพาะผู้ลงทะเบียน (`LoginMas`)

### 4.4 เวลาสุริยะจริง ✅
- แก้ลองจิจูด: `(ลองจิจูด − เขตเวลา×15) × 4 นาที` + สมการเวลา (`Diff_MST`) − DST
- ใช้เมื่อเลือกคำนวณเวลาเกิดจริง (`CalBTimeType = 1`)

### 4.5 เสาวัน ✅
- `CalFnDay`: นับวันจาก 19 ก.พ. 1900 `mod 60` (ผลต่าง 0 = วัน 癸亥 เพราะ APK ปรับเลข 0 เป็นก้านที่ 10 / กิ่งที่ 12)
- โหมดมาตรฐาน + ยามแบบ 23:00 → หลัง 23:00 นับเป็นวันถัดไป

## 5. บุคคล

### 5.1 เลข Kua / 命卦 ✅ (`CalManCode`)
- ชาย: `(2549 − ปีเกิด) mod 9` · หญิง: `(ปีเกิด − 2543) mod 9` (ปรับเป็น 1–9; ปีเกิดเป็น ค.ศ.)
- ได้ 5: ชาย → 2, หญิง → 8 📘
- เกิดก่อนจุดเปลี่ยนปี (§4.2) ให้ใช้ปีก่อนหน้า
- `js/person-core.js` (`personKuaOf`) ใช้สูตรผลรวมหลักแบบตำรา ให้ผลเท่ากัน ✅
- APK ยังมี `ManCode = (2000 − ปีเกิด) mod 9` = ดาวปีเกิด (本命星)

### 5.2 แปดทิศ 八宅 📘
- APK F12 **ไม่มีตาราง 八宅** · แอปเราใช้ตารางมาตรฐาน 八宅明鏡 ใน `person-core.js` (`PERSON_8M_TABLE`) ตรวจความสมมาตรแล้ว
- กลุ่มตะวันออก Kua 1 3 4 9 · ตะวันตก 2 6 7 8
- บ้านกลุ่มตะวันออก = นั่ง N S E SE

### 5.3 กัวกับสมาชิกบ้าน (ใช้กับมุมขาด) 📘
N 坎 ลูกชายคนกลาง · NE 艮 ลูกชายคนเล็ก · E 震 ลูกชายคนโต · SE 巽 ลูกสาวคนโต · S 離 ลูกสาวคนกลาง · SW 坤 แม่ · W 兌 ลูกสาวคนเล็ก · NW 乾 พ่อ

## 6. ทิศร้ายตามเวลา ✅ (`CalSanSha`, `DrawSanSha`)
APK แสดงต่อชั้นเวลา ปี/เดือน/วัน/ยาม 3 แบบ (ชื่อตามแอป):
| ชื่อในแอป | ตำรา | สูตร |
|---|---|---|
| **ทิศอสูร** | 三煞 | ทิศหลัก 90° ตามกิ่ง: `quadrant = (15 − กิ่ง) mod 4` โดยกิ่ง 1 = 子, quadrant 0 = N, 1 = E, 2 = S, 3 = W (申子辰 → S, 寅午戌 → N, 巳酉丑 → E, 亥卯未 → W) |
| **ทิศแตก** | 歲破/月破 … | ทิศนักษัตรตรงข้าม (กิ่ง + 6) ช่องละ 30° |
| **ทิศเบญจภูติ** | ดาว 5 (五黃) | วังที่ดาวจร 5 ตกในชั้นเวลานั้น |
- คำเตือนในแอป (สรุป): ทิศเหล่านี้ห้ามซ่อม ต่อเติม เจาะ ขุด รื้อ ถ้าบ้านนั่งทิศนี้ห้ามทั้งหลัง
- ไท้ส่วยประจำปี และ "อ๊ำเกี๋ยง" ประจำเดือน = ทิศที่ควรระวังการตกแต่ง
- ประตูเมือง (城門) และประตูเมืองแฝง = ทิศพลังแฝง ต้องใช้ร่วมกับดาวดี
- แอปเรา (`calc.js`) มีทิศชง/ทิศอสูรรายปีแบบมาตรฐาน (ยังไม่เลื่อน 15° แบบ อ.มาศ)

### 6.1 空亡 ✅ (`ChkKongBoung`)
- กิ่งว่างของเสา = `(กิ่ง − ก้าน + 12)` และค่าก่อนหน้าอีกหนึ่ง (ปรับ 1–12)

## 7. แปลนบ้าน
- APK มี "หาจุดศูนย์กลาง": จิ้มมุมรอบอาคารเป็นรูปหลายเหลี่ยม แล้วหา **centroid แบบถ่วงพื้นที่** (สูตร shoelace) ✅ — แอปเรายังใช้กรอบสี่เหลี่ยม 2 มุม (เหมาะกับทาวน์เฮาส์) ถ้าจะรองรับบ้านรูปทรงไม่ปกติให้ใช้สูตรนี้
- APK วัดทิศจากแผนที่ดาวเทียมได้ และเตือนว่าอาคารสูงในภาพดาวเทียมอาจเอียง ให้วัดจากแผนที่ลายเส้นแทน
- APK มีปุ่มหมุนผังบ้านครั้งละ 90° หรือครั้งละ 1 ช่วงพลัง เพื่อเปรียบเทียบดีร้าย

## 8. สิ่งที่แอปเรากำหนดเอง 🔧 (หน้า `plan.html`, `js/plan.js`)
ยังไม่ได้มาจากตำราหรือ APK ใด ควรแทนด้วยเกณฑ์จาก APK วิเคราะห์ผังบ้านเมื่อได้ไฟล์
- คะแนนดาวตามจังหวะ: รุ่ง +3 · กำลังมา +2 · ถอย 0 · อ่อน −1 · ดาว 5 −3 (`TL_SCORE`)
- น้ำหนัก [ดาวภูเขา, ดาวน้ำ] ตามประเภทห้องจากชื่อ (`WEIGHT`): ห้องนอน 1.5/0.5 · ประตู 0.5/1.5 · ห้องนั่งเล่น/ทำงาน 0.7/1.3 · ครัว/ห้องน้ำ/ห้องเก็บของ 0.5/0.5 · บันได 1/0.5 · ห้องพระ 1.2/0.5 · อื่น ๆ 1/1
- 八宅 ของเจ้าของ: 生氣 +3 · ดีอื่น +2 · 禍害 −1 · 六煞/五鬼 −2 · 絕命 −3; ห้องครัว/ห้องน้ำ/ห้องเก็บของ คิดกลับด้าน × 0.4 (ควรอยู่ทิศร้าย)
- ผล: ≥ 4 ดีมาก · ≥ 1.5 ดี · ≥ −0.5 ปานกลาง · ต่ำกว่านั้น ระวัง · ช่องที่ทำเครื่องหมายเป็นมุมขาด

- คำแนะนำเติมมุมขาด (ไฟส่องขึ้น กระจก ต้นไม้) และคำเตือน 五黃/二黑 จรปี
